# 全国电网代购电价与电量分析仪表盘

基于全国 32 个省级电网（含冀北、河北南网、蒙西、蒙东等区域电网）2026 年逐月《代理购电价格公告》整理的可视化分析平台。

## 功能模块

- **全国概览**：某月各省电网代购价 / 综合平段电价排名，购电规模对比
- **地区详情**：单省月度价格构成明细（购电价 + 线损 + 输配电价 + 基金 + 系统运行费）
- **趋势对比**：2025 vs 2026 跨年价格走势、构成堆叠、多省横向对比
- **入市签约对比**：入市交易与电网代购综合平段价差、签约划算程度分析

## 技术说明

- 数据：2026 年 1-9 月各省《代理购电价格公告》（滚动更新）
- 口径：综合平段电价 = 购电价 + 上网环节线损电价 + 电度输配电价 + 政府性基金及附加 + 系统运行费折价
- 输配电价按 2026 年 8 月 1 日新版执行前后分段取值
- 纯前端单文件（ECharts），无后端依赖，可直接部署为静态页面
