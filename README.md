# 全国电网代购电价与电量分析仪表盘

基于全国 32 个省级电网（含冀北、河北南网、蒙西、蒙东等区域电网）2026 年逐月《代理购电价格公告》整理的可视化分析平台。

## 在线访问

- **仪表盘**：https://shuazi480.github.io/shuaz1-power-dashboard/
- **PDF 数据导入页**：https://shuazi480.github.io/shuaz1-power-dashboard/parse-pdfs.html

## 功能模块

- **全国概览**：某月各省电网代购价 / 综合平段电价排名，购电规模对比
- **地区详情**：单省月度价格构成明细（购电价 + 线损 + 输配电价 + 基金 + 系统运行费）
- **趋势对比**：2025 vs 2026 跨年价格走势、构成堆叠、多省横向对比
- **入市签约对比**：入市交易与电网代购综合平段价差、签约划算程度分析

## 每月数据更新流程（免爬虫）

各省电网公告网站有反爬机制，因此采用「人工下载 PDF → 页面内解析」的可迭代流程：

1. 每月初到国网 / 南网 / 蒙西电网官网，下载各省《代理购电价格公告》PDF
2. 打开 **parse-pdfs.html**，把 PDF 拖入上传区（可多选）
3. 页面在浏览器本地解析出 省份 / 月份 / 代理购电价格 / 线损 / 输配电价 / 基金附加 / 系统运行费
4. 核对预览表 → 点「应用」：数据写入浏览器 localStorage，仪表盘立即使用新数据
5. 若要长期共享：点「导出 data.json」，替换仓库里的 `data.json` 并推送

> 文件名建议包含省份与月份，如 `江苏2026年8月代理购电价格公告.pdf`，识别最准确。

## 技术说明

- 数据：2026 年 1-10 月各省《代理购电价格公告》（滚动更新）
- 口径：综合平段电价 = 购电价 + 上网环节线损电价 + 电度输配电价 + 政府性基金及附加 + 系统运行费折价
- 输配电价按 2026 年 8 月 1 日新版执行前后分段取值
- 纯前端静态页（ECharts + PDF.js），无后端，PDF 解析全程在本地浏览器完成
- 本版已按需求移除「签约价构成」「绿电专区」两个模块
